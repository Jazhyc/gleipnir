\section{Team}
\label{sec:team}
I am the sole investigator and will work on the project full time. I am the
first author of the Gleipnir v1 technical report \citep{ferrao2026gleipnir},
whose code, weights, teacher probabilities and serving image are public.
I built the teacher data, the training method and the serving stack, ran the
main and SleightBench evaluations, and prepared the release; my co-author
Abhinav Rajeev Kumar ran the evaluations on reward hacking and backdoored
programs.
\todo{other relevant track record, if any.}
Gleipnir v1 was supported by a BlueDot Impact Rapid Grant, which paid for the
teacher API credits, and by the exploration phase of Neel Nanda's MATS stream.

The project is short and fast-paced. It is planned for one person: each aim
starts from the v1 training pipeline, evaluation suite and serving stack rather
than from scratch. The end date is fixed: I start the MATS main phase in
mid-January 2027, and collaborating with researchers outside the program may
be difficult then, so v2 is planned to be finished and released before it
begins.

The plan assumes no other contributors. If others join, they would mainly run
additional evaluations, while I continue the training and serving work.
