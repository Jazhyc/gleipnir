\section{Setup of Sinha et al.}
\label{app:sinha-setup}

This appendix gives the details of the setup of \citet{sinha2026training} that Section~\ref{sec:background-sinha} leaves out.

\paragraph{Training targets.}
The teacher is Gemini 2.5 Pro.
For each training trajectory, it reads the scheming specification and writes four candidate outputs.
Each candidate is a rationale in four parts (observations, the case that the agent is innocent, the case that it is misaligned, and a conclusion) that ends in a score from 0 to 10.
A score of 5 or more marks the trajectory as harmful, and a candidate whose score disagrees with the label is regenerated with guidance from the label.
A judge, Claude Sonnet 4.5, then rates the quality of each candidate from 0 to 10.
Only the candidate with the highest rating is kept, and only if its rating exceeds 7.
The monitor is trained on the kept candidates with SFT.
For the Qwen3.5 models, an RL stage with Group Relative Policy Optimization follows, which starts from the SFT checkpoint.
Its reward combines a Brier-style calibration term with a pairwise ranking term.
The trained monitor never receives the specification, in training or at inference.
Only the teacher and the prompted baselines receive it.

\paragraph{Data.}
Table~\ref{tab:sinha-data} lists the training set, the validation set and the OOD suite.
Where a source includes the chain of thought of the agent, Sinha et al.\ remove it.
Appendix~\ref{app:data-discrepancies} records where the prepared data departs from this description.
They also drop every trajectory with more than 28,000 tokens, which leaves 4,000 tokens of headroom in the 32,000-token context of their shorter-context models.
The training set is balanced between benign and harmful trajectories within each source.
The validation set has two parts: STRIDE trajectories from held-out settings, and Gloom-Exfiltration, a variant of Gloom.
For the OOD suite, the table gives the 6,395 trajectories in the prepared inputs of Sinha et al., which are the trajectories that we score.
The dataset table in their paper lists 856 trajectories for SHADE-Arena and 1,500 for Rogue Eval, which gives 6,402 in total.

\paragraph{Metric.}
Let $\mathrm{TPR}(u)$ be the true-positive rate of a monitor at false-positive rate $u$.
The metric is
\begin{equation}
\text{pAUROC@20} = \frac{1}{0.2}\int_{0}^{0.2} \mathrm{TPR}(u)\,\mathrm{d}u ,
\end{equation}
so a perfect monitor scores 1.
Mean-OOD is the unweighted mean of pAUROC@20 over the six OOD benchmarks.

\paragraph{Cost.}
The cost of a monitor is its inference cost in USD per 1,000 evaluations.
Sinha et al.\ compute it from the standard API price per input and output token, without batch or caching discounts.
For open-weight models, they use the price of hosted inference for a comparable base model, not the cost of self-hosting.
Table~\ref{tab:ood-all} in Appendix~\ref{app:ood-results} lists the scores and costs that they report.

\section{Data sources and discrepancies}
\label{app:data-discrepancies}

We use the data that \citet{sinha2026training} published on Hugging Face (Table~\ref{tab:hf-data}), and we place each trajectory unchanged between the trajectory tags (Appendix~\ref{app:prompts}).

This appendix names the files and records two places where they differ from that description.
Both are properties of the files: we do not process the trajectories, apart from the removal of reasoning from the validation set.

\paragraph{Agent reasoning in the STRIDE training set.}
The training trajectories of STRIDE contain the reasoning of the agent.
Of the 1,350 STRIDE training trajectories, 1,269 contain reasoning blocks that are flattened into the assistant messages, 1,230 contain explicit calls to a \texttt{think} tool, and 1,340 contain at least one of the two.
These are 15.4\% of the 8,688 training trajectories.
We found no \texttt{think} calls in the other four training sources.
We found this reasoning only after we had cached the targets of the teacher, so the teacher computed its targets on these inputs.
The Gleipnir monitors are trained on the same inputs.
We did not remove the reasoning afterwards: removing it only for the monitor would give the teacher information that the monitor lacks, and removing it for both requires new teacher targets.

\paragraph{Validation set.}
For the validation set we removed the typed reasoning of the agent and its \texttt{think} calls, and kept the assistant messages, the other tool calls and the tool results.
All validation scores in this report use this version, which has 3,012 trajectories.

\paragraph{No assistant messages in the OOD suite.}
The OOD inputs are stricter than the description that Sinha et al.\ give: they contain no private reasoning of the agent, and most of them also contain no assistant messages at all.
In the four benchmarks that come from ControlArena (AgentDojo, IaC, Rogue Eval and SHADE-Arena), every assistant message has an empty body, and only the tool calls and the tool results remain.
In CUA-SHADE-Arena, the assistant messages contain only the names of the tool calls.
Only MLE-Sabotage keeps assistant messages: for each step, the input shows the short plan that the agent states, the code that it submits and the output of that code.
This is the input that SleightBench uses as its main setting, which removes all assistant messages and keeps the user messages, the tool calls and the tool results.
A monitor on the OOD suite therefore judges tool calls and tool results, and it does not see what the agent reported to the user.
The training set and the validation set do keep the assistant messages, so the monitors are trained on a wider input than the OOD suite tests.
We cannot be certain that the experiments of Sinha et al.\ used these published files, so this difference may not apply to the scores that they report.
We keep the OOD inputs unchanged so that our scores stay as comparable as possible with theirs.
The public source files did not allow us to restore the missing text for 6,247 of the 6,395 trajectories.

\subsection{Teacher-agreement filter}
\label{app:ablation-filter}

The filter of Section~\ref{sec:binary-logit-distillation} removes 852 of the 8,688 training trajectories.
We chose it in part for a practical reason: it shortens a training pass from 272 to 245 updates.
We also compared training with and without the filter on one run of the 4B (Table~\ref{tab:filter}).
The filter raised the score on the validation set from 0.847 to 0.896 and Mean-OOD from 0.776 to 0.787.
The gain on the OOD suite is therefore about a fifth of the gain on the validation set.

A filter with a margin $\delta$ keeps the disagreeing trajectories on which the teacher is uncertain: it removes a harmful trajectory only when $p < 0.5 - \delta$ and a benign trajectory only when $p > 0.5 + \delta$.
We tested three margins on the validation set.
Each scores below the filter without a margin, and the scores do not fall steadily with the margin (0.879, 0.836 and 0.851).
In these runs, keeping the uncertain trajectories did not help.

\subsection{Soft targets against hard labels}
\label{app:ablation-targets}

We test the effect of the soft targets by training on the dataset labels instead (hard labels), with all other settings of Section~\ref{sec:training-setup} unchanged (Table~\ref{tab:hard-soft}).
All runs read the compact instruction and use BF16 serving.
For the 4B, we compare three runs for each objective.
Soft targets raise the mean Mean-OOD from 0.716 to 0.792 and the mean validation score from 0.833 to 0.903, and every soft-target run scores above every hard-label run on the OOD suite.
For the 27B, we have one run for each objective, and the result differs.
On the OOD suite, the two objectives score within 0.005 of each other.
On the validation set, the hard-label 27B scores 0.044 higher.
Soft targets therefore help the 4B on both sets, and they do not help the 27B.
One explanation is that soft targets add less when the unadapted model is already close to the teacher.
We cannot separate this from the size of the model with two models, and we leave it open.
\citet{geuter2026releasing} report a similar pattern for decision models: soft targets give no measurable change for their 31B model, while distillation from that model raises the score of Qwen3.5-4B.
Their tasks, metric and teacher differ from ours.
