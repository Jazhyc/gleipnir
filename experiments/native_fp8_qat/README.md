# Native FP8 QAT quality test and MXFP8 backward diagnostic

Hypothesis: native FP8 attention projections provide useful complete-update
speedups and retain ID quality after fixed-epoch QAT, despite failing the previous
trajectory-reproduction gate. This is a new training variant, not an equivalence
claim or a waiver of the historical failed receipt.

Use the existing authorized NC2 B200, original strict-filtered 7,836 rows,
completed BF16 monitor teacher cache, initial FP32 adapter, seed-zero order,
245 updates, binary KL T1, AdamW 1e-5 and original packing/context contract.
Enable native FP8 FP32-accumulating projection GEMMs plus the numerically accepted
MLP/GDN structural optimizations. Retain MXFP8 forward with FA4 surrogate backward
for this quality arm. Reuse unchanged operator checks, but freshly check simulator
alignment against archived optimized-server scores (MAE <=0.02, correlation
>=0.99), packing isolation and longest-row finite-gradient/memory support.
Gradient/trajectory reproduction is explicitly not an acceptance criterion.
Stop on nonfinite/missing gradients, input/source/runtime drift, unsupported
execution, OOM or failed alignment/isolation. The quality run cap is two hours.

Select the fixed final epoch only; merge FP32 adapters into the same owned
ephemeral BF16 slot, preserving the previous merge manifest and research masters.
Run new-adapter parity and two frozen 3,012-row CoT-removed ID passes on optimized
vLLM. Compare cached completed QAD, BF16 and original optimized predictions;
report macro raw normalized pAUROC@20, pooled/per-source AUROC, calibration,
thresholds, ties and serving input tokens/s. For descriptive quality acceptance,
require mean macro pAUROC no more than 0.005 below completed QAD's 0.87608417;
never tune or promote on ID/OOD. Compare first twenty-update timings against the
existing matched structural-optimization receipts. No new teacher calls, Kimi
training or OOD evaluation occurs.

Separately test native MXFP8 backward. Reuse the existing packed native dQ/dK/dV
host and scale/scratch handling, but obtain LSE from a hardware-exp2 forward with
the serving arithmetic. Check mixed lengths, singleton and sequence isolation,
finite gradients, agreement to the existing forward, and approximate-gradient
deviations versus the FA4 surrogate. Benchmark complete attention forward/backward
including conversion/repacking/scratch. These probes do not change the quality arm.
Historical strict native-vs-BF16 gradient failures remain preserved.

Frozen original train/reference/evaluation scripts are transformed into archived
experiment-specific entrypoints through checked substitutions. Their source
hashes, generated bytes and exact replacements are recorded; historical scripts
and receipts are unchanged. The pipeline automatically trains, exports and scores
or stops with a failure receipt. Retire the completed timing worker because its
fixed queue cannot accept the new campaign; reuse persistent compiler caches.
This session has no in-chat scheduler, so detached automation does not promise
later agent wakeups. Monitor startup and diagnostics during the active turn.
